# CMU 3D — Architecture & Module Contract

Explorable 3D recreation of Carnegie Mellon University's Pittsburgh campus (fan project, unofficial).
Real geometry from OpenStreetMap (buildings, roads, paths, lawns, trees, POIs) and real terrain (AWS Terrain Tiles z15),
rendered with three.js r170. UI language: **Simplified Chinese first**, English names alongside.

The page must work by **double-clicking `index.html`** (file://). Therefore:
- No `fetch()` of local files, no ES-module `<script type=module src=local>`. Data is loaded by classic `<script>` tags
  (`data/campus.js` → `window.CAMPUS_DATA`, `data/info.js` → `window.CAMPUS_INFO`).
- All code in `src/` is ES modules bundled by esbuild into `dist/app.js` (IIFE). `npm run build`.
- No external runtime assets except optional Google Fonts (must degrade gracefully offline). Textures are painted on
  `<canvas>` at runtime. No image files, no model files, no audio files.

## The context object `ctx` (src/core/context.js)

Created once in `main.js` and passed to every module.

| field | provided by | description |
|---|---|---|
| `THREE` | context | the three.js namespace (modules may also `import * as THREE from 'three'`) |
| `data`, `info` | context | CAMPUS_DATA, CAMPUS_INFO |
| `isMobile`, `quality` | context | quality = `{ level:'low'|'medium'|'high', shadows, shadowMapSize, pixelRatio, treeDensity, npcCount, groundTextureSize, antialias, post, drawDistance }` |
| `events` | context | `on(name, fn)→off`, `off`, `emit(name, payload)` |
| `onUpdate(fn(dt, elapsed), order=0)` | context | per-frame callback; returns unsubscribe. Controls use order −10, env 0, world 10, UI 100 |
| `heightfield`, `heightAt`, `normalAt` | context | terrain lookups (available before the terrain mesh exists) |
| `surfaceHeightAt(x, z, fromY?)` | context | max(terrain, walkable meshes below fromY+1.2) — used by walk mode |
| `pick` | context | `add(object3D, entry | (hit)=>entry)`, `remove`, `objects()`, `resolve(hit)` |
| `labels` | context | `add({key, text, textZh, kind, priority, position:{x,y,z}, maxDistance?})`, `remove(key)`, `items` (Map) |
| `colliders` | context | `addPolygon(ring, yMin, yMax, tag)`, `addCircle(x,z,r,yMin,yMax,tag)`, `addBox(cx,cz,hw,hd,rotY,yMin,yMax,tag)`, `resolve(pos, radius, height)` |
| `walkables` | context | `add(mesh)` — meshes you can stand on above the terrain (bridge decks, stairs, terraces) |
| `skipBuildingIds`, `skipRoadIds`, `skipBarrierIds` | main.js | ids replaced by landmark models — generic builders MUST skip them |
| `yield()` | context | await between heavy chunks so the loading screen repaints |
| `loading` | ui | `step(label, 0..1)`, `detail(text)`, `done()`, `error(msg)` |
| `renderer`, `scene`, `camera`, `canvas`, `engine` | engine | see §engine |
| `env` | env | see §env |
| `materials` | materials.js | see §materials |
| `terrain` | terrain | `{ mesh, heightAt, normalAt, groundTexture? }` |
| `buildings` | buildings | `{ list, byId(id), highlight(id|null) }` |
| `nav` | controls | see §controls |
| `ui` | ui | see §ui |
| `landmarks` | main.js | `[{ key, name, nameZh, osmIds, object }]` after build |

Pick entries: `{ key, kind:'building'|'landmark'|'poi'|'area', name, nameZh, osmId?, infoKey?, position:[x,y,z], radius }`.
`infoKey` looks up `CAMPUS_INFO.buildings[osmId]` / `CAMPUS_INFO.landmarks[key]` / `CAMPUS_INFO.pois[name]`.

### Init order (main.js)
engine → env → materials → terrain → roads → buildings → each landmark.build → vegetation → props → life →
controls → UI → `engine.start()` → `loading.done()` → `events.emit('app:ready')` → `window.__READY = true`.
Every step is wrapped in try/catch: a failing module logs an error and the rest still loads — so never throw
for recoverable problems; `console.warn` and continue.

### Events (names are fixed)
- `env:change` (state) — time of day changed (throttled by env to ≤ 10 Hz)
- `env:season` (season) — 'spring'|'summer'|'autumn'|'winter'
- `nav:mode` ({mode}) — 'orbit'|'walk'|'fly'
- `select` (entry|null) — user selected something (UI emits; buildings highlight listens)
- `hover` (entry|null)
- `app:ready`
- `world:complete` — on q=low the trees/props/traffic are built after the first frame (progressive start); fired when done
- `perf:degrade` ({level, cpu, gpu, pixelRatio, ao}) — engine lowered resolution/effects to hold the frame rate
- `terrain:surroundings` — the procedural area beyond the data finished building (during the first frames)
- `quality` (qualityPreset) — quality level changed at runtime (engine emits after applying)

## §engine — `src/core/engine.js` → `createEngine(ctx, canvas)`
Sets `ctx.renderer` (WebGLRenderer, sRGB output, ACES tone mapping, PCFSoft shadows per quality), `ctx.scene`,
`ctx.camera` (PerspectiveCamera fov ~55, near 0.5, far ≥ 6000), `ctx.canvas`, and `ctx.engine = { start(), render(),
resize(), setQuality(level), stats() }`. The loop calls `ctx.tick(dt, elapsed)` then renders (optionally through a
post-processing composer when `quality.post`). Clamp dt ≤ 0.1 s. Handle resize and devicePixelRatio. In `?shot` mode keep
rendering even without focus.

## §env — `src/core/env.js` → `createEnvironment(ctx)`
Shadow maps are refreshed by env (autoUpdate off): call `ctx.env.refreshShadows()` after moving static casters.
`ctx.env.sunNear` is a second, near shadow cascade on high. `ctx.materials.enhance(root)` adds procedural normal maps.
Sky dome (physically-based feel: Preetham `Sky` from three/examples or custom shader), sun `DirectionalLight` with a
shadow camera that follows the camera focus (tight frustum around what is visible, texel snapping to stop shimmer),
hemisphere/ambient light, fog matched to sky horizon colour, `scene.environment` (PMREM of the sky, refreshed when the
time changes significantly). Real Pittsburgh sun path (lat 40.44 N, EDT) for a date matching the season. Night: moon
light, stars, darker blue fog; emits nightFactor for emissive windows/street lamps.
**Defaults: season 'autumn' (early fall — mostly green trees with yellow/orange/red accents), hours 15.0.**
URL `?hours=` and `?season=` override.
`ctx.env = { sun, hemi, state:{ hours, sunDir(Vector3, towards sun), nightFactor 0..1, season }, setTime(h), getTime(),
setTimeSpeed(k) (0 = frozen; default 0), setSeason(s), setWeather?(w) }`.

## §materials — `src/core/materials.js` → `createMaterials(ctx)` (already implemented, read-only for agents)
`ctx.materials = { palette, get(name), color(hex, opts), facade(opts), surfaceTexture(kind, color, tileM),
registerNightMaterial(mat, k), applyWorldUV(geometry, matrix?), shade(hex, f), makeCanvas, canvasTexture, rand }`.
- `get(name)` shared presets: brickYellow brickBuff brickRed brickBrown limestone sandstone granite concrete
  concreteDark stucco terracotta white copperRoof tileRoof slateRoof metalRoof flatRoof zinc aluminium darkMetal bronze
  gold glass glassDark glassGreen glassClear wood asphalt sidewalk paver grass water cmuRed windowLit.
- **UVs are in metres.** Call `applyWorldUV(geometry, matrix?)` on geometry before use (box projection) or generate
  metre UVs yourself. For facade materials, `v` must start at 0 at the building's ground level so storeys line up.
- `facade({ wall, wallColor, style:'punched'|'arched'|'ribbon'|'curtain'|'none', bay, floor, winW, winH, sill, frame,
  glass, trim, lit, seed })` → wall material with windows + night-lit emissive map. **Walls only** (never roofs).
- Materials are cached — reuse them; don't create per-mesh materials in loops.
- Night emissive is driven automatically from `ctx.env.state.nightFactor`.

## §terrain — `src/world/terrain.js` → `async createTerrain(ctx)`; `src/world/roads.js` → `async createRoads(ctx)`
Terrain mesh from the heightfield plus a large low-detail skirt/ring beyond the data bounds fading into fog (no visible
world edge from normal viewpoints). Ground material = big painted texture (size `quality.groundTextureSize`) covering
the data bounds: grass base with variation, areas by type, roads (asphalt, lane markings, crosswalks, curbs/sidewalks),
footpaths (concrete/pavers), steps, parking stalls, sport pitches & the running track with lines, water. Close-up detail
via shader tiling noise so grass/asphalt don't look blurry. Areas & roads must follow the terrain (they're painted into
the terrain texture, so they do). Roads with `bridge:true` are NOT painted; `createRoads` builds 3D decks with railings
for them (interpolate deck height between the bridge ends, add piers), registers decks in `ctx.walkables`, railings in
colliders. Also: railway tracks in Junction Hollow, 3D barriers (fences/walls/retaining walls; hedges are vegetation's),
cliffs (rock faces), water surfaces (Westinghouse Pond, fountains). Skip ids in `ctx.skipRoadIds` / `ctx.skipBarrierIds`.

## §buildings — `src/world/buildings.js` → `async createBuildings(ctx)`
All `data.buildings` except `ctx.skipBuildingIds` (match `b.osmId` **or** `b.id`) and `b.hidden`.
Vertical placement MUST use `buildingLevels(b)` from `core/placement.js`. Walls with facade materials chosen by
`b.style` (curated) or inferred from type/tags/campus; roofs by `roofShape` (flat w/ parapet + rooftop units, gabled,
hipped, pyramidal, skillion, dome, round) with roof materials; holes (courtyards) supported. Merge geometry by material
per spatial chunk (~250 m) for performance (target < 300 draw calls for all buildings). Cast/receive shadows.
Colliders: `ctx.colliders.addPolygon(footprint, baseY, roofY, id)`. Picking: register merged meshes with a resolver
using a per-vertex building index attribute. Labels: named buildings → `ctx.labels.add(...)` (campus priority 6,
others 3; position above the roof centroid). `ctx.buildings = { list, byId, highlight(id|null) }` (highlight = subtle
emissive/outline on hover/selection; listens to `select`/`hover` events).

Curated `style` vocabulary (data/curated/buildings.json → b.style):
`beaux-arts` (Hornbostel buff brick, arched windows, terracotta trim, pale grey-green standing-seam roofs — originally green Ludowici tile — with verdigris copper eaves) · `collegiate-brick`
(buff/yellow brick, punched windows) · `modern-brick` · `modern-glass` · `curtain-wall` · `brutalist` · `limestone-classical`
· `gothic-stone` · `residential-brick` · `house` · `parking` · `industrial` · `terracotta-modern`.
Optional curated `facade:{...}` passes straight into `materials.facade()`, `roof:{shape, material, color}`.

## §landmarks — `src/landmarks/<file>.js`
Each file: `export default [ landmarkDef, ... ]` where
```js
{
  key: 'hamerschlag',                 // unique
  name: 'Hamerschlag Hall', nameZh: '哈默施拉格楼',
  osmIds: ['w27551077'],              // generic buildings this replaces (buildings.js will skip them)
  skipRoads: [], skipBarriers: [],    // optional: road/path/barrier ids this model replaces
  async build(ctx) { /* return a THREE.Object3D positioned in WORLD coordinates */ },
}
```
Model from real references (web research): proportions, massing, roof forms, colonnades, materials and colours matter
more than tiny detail. Fit the OSM footprint (`footprintFrame(ring)` gives centre / long-axis angle / size) and use
`buildingLevels(b)` (or terrain `ctx.heightAt`) for ground height; walls must reach the ground on slopes (extend below).
Use `ctx.materials` presets/facades (metre UVs!). Also: register colliders (`ctx.colliders.addPolygon/addBox`), pick
entries (`ctx.pick.add(object, { key, kind:'landmark', name, nameZh, osmId, position, radius })`), and a label
(`ctx.labels.add({ key, text, textZh, kind:'landmark', priority: 9, position })`). castShadow/receiveShadow on meshes.
Merge static sub-meshes by material (BufferGeometryUtils.mergeGeometries) — keep each landmark < ~40 draw calls
and < ~300k triangles. Night: lit windows via facade materials or `windowLit`, optional floodlights (emissive only;
avoid many real lights — at most 2 PointLights per landmark and only if `ctx.quality.level === 'high'`).

## §vegetation / §props / §life — `src/world/{vegetation,props,life}.js`
Instanced meshes only. Trees: OSM trees + tree rows + scattered in wood/park/golf areas + street trees, avoid
buildings/roads/paths (use footprints & road buffers), several species (deciduous rounded, maple, oak, conifer,
ornamental), per-instance colour/scale variation, wind sway in the vertex shader, seasonal colours via `env:season`,
density `quality.treeDensity`. Hedges from `barriers` type hedge. Props: benches (`pois` type bench, face nearest path),
street lamps along paths/roads (emissive at night), bins, bike racks, bollards, parked cars in parking areas.
Life: pedestrians along the footway graph (walk animation), cars on main roads (Forbes Ave, Fifth Ave, Morewood, Craig,
Schenley Dr), respect `quality.npcCount`. People/cars should not walk through buildings.

## §controls — `src/controls/controls.js` → `createControls(ctx)`
`ctx.nav = { mode, setMode('orbit'|'walk'|'fly'), setView(camPos[3], target[3]) (instant, switches to orbit),
flyTo({ target:[x,y,z], distance?, position?:[x,y,z], duration? }) → Promise, walkTo(x, z, headingRad?) (enter walk
mode at ground level), getState() → { mode, position, target, heading }, enabled (false while UI has focus) }`.
- Orbit (default): left-drag rotate, right-drag / two-finger pan, wheel / pinch zoom, damping, keep camera above
  terrain + 2 m and within bounds, max polar angle ~85°, distance 15…2500 m. Double-click = fly to the point.
- Walk: pointer lock on desktop (click to lock, Esc to release), WASD/arrows, Shift run, Space jump, eye height 1.65 m,
  gravity onto `ctx.surfaceHeightAt`, collisions via `ctx.colliders.resolve`, gentle head bob, can climb stairs/slopes ≤ 0.5 m steps.
  Mobile: left virtual joystick + right-side drag to look.
- Fly: free camera, WASD + E/Q up/down, mouse-drag look, wheel changes speed.
- Keys owned by controls: W A S D Q E Shift Space Arrow keys. (UI owns: M map, T tour, H or ? help, L labels,
  N night toggle, 1/2/3 mode buttons, / or F search, Esc close panels.)
- Emits `nav:mode`. Exposes `window.__setView` via main.js.

## §ui — `src/ui/ui.js` → `createLoadingScreen(ctx)`, `createUI(ctx)`

- Loading screen: title, progress bar, step labels, tips; fades out on `done()`.

- Labels renderer: HTML labels projected from `ctx.labels`, declutter by priority/distance, fade with distance, hide

- Hover tooltip + click → info panel (name zh/en, photo-less but rich: year, architect, style, what's inside, facts,

- Search (buildings, landmarks, POIs, areas; pinyin not required; zh + en substring match) → flyTo.
- Minimap (canvas, top-down footprints, roads, green areas; camera marker + view cone; click to fly/teleport; toggle M).

## Testing your module in isolation (REQUIRED before you finish)
1. Write an entry in `.scratch/<your-agent-name>/entry.js` wrapped in an async IIFE:
   ```js
   import { createHarness } from '../../src/dev/harness.js';
   import { createBuildings } from '../../src/world/buildings.js';
   (async () => {
     const ctx = await createHarness();          // renderer, scene, camera, lights, simple terrain, ctx.materials
     await createBuildings(ctx);
     ctx.harness.view([-420, 200, 380], [-150, 45, 90]);
     ctx.harness.ready();
   })();
   ```
2. `npx esbuild .scratch/<name>/entry.js --bundle --format=iife --outfile=.scratch/<name>/bundle.js --log-level=warning`
3. `node tools/shot.mjs --bundle .scratch/<name>/bundle.js --out .scratch/<name>/a.png --cam=x,y,z --look=x,y,z`
   (add `--css` to include css/styles.css; `--views views.json --outdir dir` for many views; `--eval "js"`).
   It prints console errors, page errors, draw calls and triangles. **Look at the PNGs with the Read tool** and iterate
   until it looks right. GPU is an RTX 4070 via ANGLE/D3D11, so real performance numbers are meaningful.
4. Never write to `dist/` (the integrator builds the real app). Keep scratch files inside `.scratch/<your-agent-name>/`.
5. **Full-app test with your own bundle** (after the modules exist):
   `npx esbuild src/main.js --bundle --format=iife --outfile=.scratch/<name>/app.js --log-level=warning` then
   `node tools/shot.mjs --app .scratch/<name>/app.js --query "q=high" --views views.json --outdir .scratch/<name>/shots`.
   views.json entries: `{ name, cam:[x,y,z], look:[x,y,z], hours?, season?, weather?, eval?, settle? }`.
   `?noui` hides the UI; `window.__initTimings` has per-step load timings; `window.__ctx` is the live context.
6. **Always pass `--query "q=high"`** (or medium/low) — headless Chrome is otherwise treated as low-end.
